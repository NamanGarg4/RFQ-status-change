# ERPNext Backend Customization – Request for Quotation Status Change

This repository contains code from a project where I worked on backend customizations in ERPNext, specifically focusing on changing the status of Request for Quotation (RFQ). The changes were aimed at improving workflow, automating status updates, and tailoring the system to specific business needs.


Project Overview

ERPNext is an open-source ERP system that helps manage various business processes including accounting, inventory, sales, and purchase management. In this project, I focused on:

1. Automating the status changes of Request for Quotation
2. Implementing backend logic to trigger status updates based on conditions
3. Ensuring the RFQ workflow reflects real business processes accurately



Features and Changes Made
1.Added automated status changes for RFQs
2. Implemented backend validations to ensure correct status updates
3. Customized notifications and triggers when RFQ status changes



Technologies Used
1. ERPNext – open-source ERP platform
2. Frappe Framework – web framework underlying ERPNext
3. Python – backend logic and server-side scripting
4. MariaDB / MySQL – database used by ERPNext


Getting Started

To explore or extend these customizations:
1. Install ERPNext following the official guide
2. Clone this repository into your ERPNext app directory
3. Apply the changes or custom scripts to the RFQ module
4. Test the workflow in a development environment before deploying to production
